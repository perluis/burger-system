# Sistema de Gestión - Restaurante de Hamburguesas

Sistema de gestión interno para restaurante de hamburguesas desarrollado en Go.

## Descripción
Permite gestionar menú, órdenes, inventario y generar reportes de ventas.

## Estructura del Proyecto
- `menu/` - Gestión de productos del menú
- `orders/` - Procesamiento de órdenes  
- `inventory/` - Control de inventario
- `reports/` - Generación de reportes
- `utils/` - Utilidades compartidas
